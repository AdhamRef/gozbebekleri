# تقرير تنفيذ إصلاحات قرة العيون

تقرير تنفيذ مرتبط بتقرير Gozbebekleri-QA-Report-2026-10-22.html، بتاريخ 22 أكتوبر 2026. النطاق: قرة العيون فقط. فرع الإصلاح fix/qa-report-remediation يشمل أساس فصل القوالب الموجود في العمل السابق، ولم يُدمج أو يُنشر.

## الملخص والحالة

نُفذت إصلاحات برمجية لكل BUG-01 إلى BUG-12، وحماية SRC-01. اجتاز التحقق الآلي 610 اختبارات و32 فحص HTTP. هذا ليس اعتمادًا نهائيًا لكل البنود: الفحص التفاعلي والبصري غير متاحين في هذه البيئة، وOP-01 وOP-02 ما زالا عائقين تشغيليين. مرجع الحالة قبل الإصلاح هو تقرير الاختبار السابق؛ لا ندعي إعادة تنفيذ تدفقات إنتاج أو إجراء إرسال أثناء الإصلاح.

## ما بقي أو تعذّر اختباره

- OP-01 — فشل البريد التاريخي وأسباب Invalid contact وspam/سياسة Apple لا تُصلح بتغيير واجهة أو إعادة إرسال جماعي. لم تتوفر بيانات اعتماد مزود مخصصة للاختبار أو أدلة تكفي لتأكيد السبب الجذري لسمعة النطاق/الحساب. يلزم فحص المرسل والمزود والعناوين وأسباب الرفض الدائم، ثم اختبار مستلم مخصص بأمان. إصلاح الإحصاءات BUG-08 لا يعني إصلاح التوصيل.
- OP-02 — ما زال تكوين Meta WhatsApp والمُرسِل والموافقات يحتاج إعدادًا صالحًا خاصًا بقرة العيون. لم تُنشأ بيانات اعتماد أو تُنسخ إعدادات من منبر الأقصى، ولم يحدث نشر قالب أو إرسال تجريبي حقيقي.
- المتصفح السحابي رفض الاتصال بـlocalhost، ومنع بروتوكول file لملفات الاختبار المحلية. لذلك لم تُختبر تفاعليًا القوائم والبحث والحفظ والمعاينة، ولا العرض عند 1363px والهاتف واللوحي، ولا تدفقات الأدوار عبر جلسات حقيقية. اختبارات React وAPI وHTTP ليست بديلًا يُسمى نجاحًا لهذه الخطوات.
- لا توجد قاعدة تجريبية متاحة؛ اختبارات API تستخدم بيانات وهمية، وبناء الحزمة يستخدم عنوان MongoDB محليًا غير متاح. لم تحدث كتابة أو حذف في قاعدة إنتاج، أو دفعة، أو رسالة حقيقية.
- تحتاج ترجمة محتوى المشروع الناقص استكمالًا من المحتوى المعتمد. أصلح الكود طريقة اختيار العنوان وإظهار نقص الترجمة، دون تخمين تفاصيل الحملة. كذلك لا تشمل المهمة ترجمة نص الشروط القانوني الموجود خارج بند الخصوصية؛ وجهة رابط الشروط اختُبرت فقط.
- الاستجابات المفقودة المتدفقة في Next أعادت 200 مع noindex وحمولة RSC للتعافي؛ لا يدّعي التقرير الحصول على 404 HTTP صريحة لكل حالة، ولا اكتمال ترطيب الصفحة في المتصفح.

## خطوات الاعتماد قبل النشر

1. مراجعة التغييرات على الفرع المحلي؛ لا دمج أو نشر تلقائي.
2. تشغيل البناء الافتراضي في بيئة تسمح بجلب الخطوط، أو اعتماد بناء Webpack بعد مراجعة إعداد النشر. معالجة أخطاء الأنواع القديمة أو توثيق قبولها منفصلًا؛ إعداد المشروع الحالي يتجاوزها في Next build.
3. تشغيل بيئة تجريبية ببيانات غير حقيقية ومزودين وهميين، واختبار UI لكل قناة: اختيار القسم والبحث، إنشاء قالب، إضافة اللغات وتبديلها، حفظ وتعديل ومعاينة، ربط حدث معطل وتفعيله، رفض خلط النوعين، وإزالة الربط دون انتقال القالب إلى التسويق. تحقق من عدم تكرار السجل بعد إعادة التحميل.
4. اختبار الحذف لقالب غير مستخدم ورفضه للمستخدم، وقياس شريط التنقل والسلة على 390px و768px و1363px و1536px، واختبار RTL/LTR والرجوع وإعادة المحاولة والتبرع والسلة حتى خطوة الدفع الوهمية.
5. إتمام OP-01 وOP-02 على قرة العيون، مع اختبار التسليم إلى مستلم مخصص بعد إعداد الحسابات؛ لم يُفوّض هذا التقرير إرسالًا أو نشرًا.
6. بعد نجاح هذه الشروط يمكن اعتماد الإصلاحات للنشر. الحالة الحالية: جاهزة للمراجعة البرمجية، وغير معتمدة بعد للنشر النهائي.

## إصلاح بوابة النشر: BUG-11 على بناء Vercel الفعلي

أُعيد ظهور عطل صفحة الرابط المفقود في معاينة Vercel `dpl_G55V3axihgXX4SQmfd3bjBD1q5TC` قبل الدمج: صفحة `/ar/qa-not-found-20261022` عرضت «حدث خطأ غير متوقع»، وسجل الخادم أكد `Couldn't find next-intl config file` (digest 614815110). كان إصدار next-intl 3.26.5 يضبط Webpack أو مفتاح `experimental.turbo` القديم؛ Next 16 يستخدم `turbopack.resolveAlias`، ولذلك نجحت اختبارات Webpack السابقة وفشل بناء المعاينة الحقيقي عند استدعاء getLocale.

الإصلاح الجذري: تعريف alias `next-intl/config` إلى `./i18n/request.ts` في إعداد Turbopack الحالي، مع إبقاء إعداد Webpack الخاص بالمكتبة. أضيف اختيار `QA_BUNDLER=turbopack` لفحص HTTP بدل الاقتصار على Webpack، واختبار أن كلا البناءين يرجعان إلى ملف إعداد الطلب نفسه ويحافظان على aliases الأخرى.

التحقق المحلي: 40 site-qa ناجحة (المجموع مع المجموعات السابقة 613)، و32 فحص HTTP عبر Turbopack للغات الثماني ناجحة دون خطأ إعداد next-intl. جلب الخطوط في بيئة التطوير المحلية استخدم الخط البديل؛ لا يُعد ذلك نجاح جلب Google Fonts. اختبار معاينة Vercel النهائي والنشر والتحقق من الدومين يوثقان في نتيجة التنفيذ اللاحقة.

قبل هذا الإصلاح فُحصت معاينة Vercel تفاعليًا: التواصل والخصوصية في اللغات الثماني، ربط الحقول الخمسة، عدم تجاوز عرض الصفحة عند 1363px، منع إرسال نموذج فارغ برسالة فرنسية، وظهور تاريخ المقال الفرنسي «il y a 9 mois». لم تُرسل رسالة حقيقية أو تُكتب بيانات إنتاج.
