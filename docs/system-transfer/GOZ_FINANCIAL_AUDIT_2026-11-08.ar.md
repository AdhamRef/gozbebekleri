## مقياس الأولوية
- **P0**: خطر كشف معلومات مالية/سرية أو تفعيل خصم أو فقد مال. يمنع الدمج حتى إثبات المعالجة.

## قائمة أخطاء ثبتت بمراجعة الكود قبل الإصلاح
| الرمز | الدرجة | التفسير | المعالجة المقترحة/المنفذة |
|---|---|---|---|
| FIN-01 | P1 | `/api/users/[id]` كان يحتسب `PAID` متكررًا بلا `paidAt` | شرط `PAID + paidAt` موحد لأول خصم وللتجديد |
| FIN-02 | P1 | اشتراك نشط بلا أول دفعة مؤكدة يدخل عدادات النشاط/التوقع | أهلية `ACTIVE` + دفعة مؤكدة، مع منع ازدواج عدد الخطط |
| FIN-03 | P1 | MRR لا يضرب معدل اليومي/الجمعة في مكافئ الشهر؛ ويمكن إضافة قيمة TRY/EUR كأنها USD | `chargesPerMonth` + عزل غياب سعر الصرف |
| FIN-04 | P1 | ملف المتبرع كان يستعمل `amountUSD ?? totalAmount` بعملة محلية | USD مثبت فقط، مع fallback عندما العملة أصلًا USD |
| FIN-05 | P1 | تقرير Excel/CSV وقائمة التبرعات يستخدمان `createdAt` للمدفوعات الناجحة خلافًا للبطاقات/الرسم | مرشح مشترك: `paidAt` للمقبوض و`createdAt` للمرفوض وغير المؤكد |

## معايير الإغلاق المتبقية
1. `npm ci` ثم `prisma validate/generate`، `npm run typecheck:ported-systems`، `npm run test:ported-systems`، `npm run test:content-editors` و`next build`؛ تسجل النتائج برابط تنفيذ وSHA الحالي.
2. قاعدة Mongo اصطناعية مستقلة: محاولات PAID بمواعيد إنشاء/تحصيل على جهتي منتصف ليل إسطنبول، FAILED، حالات استرداد كامل/جزئي، معاملات بنكية والرسوم ودعم الفريق، اشتراكات DAILY/FRIDAY/MONTHLY مع خطط غير مفعلة أو ملغاة.
3. مصالحة متجهة ثنائية: إجمالي المقبوضات المعروضة في لوحة التحكم = إجمالي المقبوضات في Excel = CSV، لكل فلاتر الوقت/المشروع/الحالة/الدولة/العملة/المزود والدورية. توثق استثناءات `amountUSD=null` صراحة.
4. اختبار صلاحيات HTTP محاكاة دور المتبرع والموظف والمدير، فشل 401/403 ومنع حقول الدفع الحساسة؛ التحقق من حالات فراغ الواجهة وجوال RTL/LTR دون تعديل ترجمة.
5. اختبار السجلات والفهارس وتزامن الطلبات مع ضمان بقاء أقفال التبرع السريع وطلبات الاشتراكات الجديدة وتأكيد صفر عمليات دفع.
6. التحقق من منطق **الاسترداد** عبر حالة السجل ومصدر التسوية: وجود `REFUNDED` كوسم عرض لا يثبت وجود عكس مالي أو احتساب صافي صحيح. لا تعدّ أي جزء منه مكتملًا حتى تُعتمد سياسة المحاسبة.
7. إجراء تدقيق أوسع لكل واجهة/API متأثرة خارج النطاق المالي قبل التصريح بتكافؤ الأنظمة بالكامل.
