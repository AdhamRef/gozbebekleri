# التبرع السريع — قرة العيون

## المنطق المعتمد
التبرع السريع يُعاد تصميمه لهوية ومشاريع قرة العيون، وليس باستيراد وجهات منبر الأقصى.
الحزمة المضافة أساس برمجي مستقل ومعطّل افتراضيًا، وليست واجهة تبرع جديدة مفعلة.
تُبنى واجهة الضبط لاحقًا على مشاريع الجمعية الأصلية وتُعرض بحسب لغاتها وعملاتها.

## شروط النقل الآمن
- قائمة النوايا (زكاة، إغاثة، ...إلخ) تحددها الجمعية، دون وجهات ثابتة من منبر الأقصى.
- كل نية/تصنيف يجب أن يحسم إلى مشروع واحد معتمد قبل السماح بالمتابعة.
- يرفض الحفظ عند وجود تكرار للوجهات أو مبلغ غير صالح أو وجهة افتراضية غير متاحة.
- التحقق البرمجي الحالي يُرجع **مرشحًا** للمشروع فقط؛ يجب تكرار التحقق على الخادم من حالة المشروع ونشره وعدم حذفه عند تحويله للسلة.
- دورية التبرع تُعرض فقط إذا كان نظام التحصيل القائم للجمعية يدعمها ويثبت نجاحها.
- لا مساس بالبوابات المالية أو البيانات القائمة أو جداول التحصيل.

## الباقي قبل التفعيل
- ربط النموذج بإعدادات قاعدة الجمعية عبر واجهة إدارة محمية بالصلاحيات وسجل تغيير.
- إنشاء واجهة مصممة لقرة العيون وترجماتها، ومعاينة الهاتف وسطح المكتب.
- بناء API للتحقق من المشروع المسموح به في لحظة إضافة السلة.
- اختبارات الواجهة وسلة التبرع والدفع، والتأكد من عدم ظهور الأداة قبل الموافقة.
