# خطة نقل الأنظمة — دون بيانات ودون SMS

## حدود النقل الملزمة
- نقل الشيفرة ومنطق العمل والاعتمادات والتكاملات فقط.
- يمنع نقل المتبرعين والتبرعات والمستخدمين والصلاحيات الفعلية والسجلات والمحادثات والمحتوى والمشاريع والصور والقوالب المحفوظة وقيم المفاتيح والمعرفات وحسابات المزودين من منبر الأقصى.
- بيانات الجمعية الموجودة تبقى في مكانها. لا استيراد لقاعدة المصدر ولا تشغيل seed أو backfill أو إعادة تعيين بيانات.
- SMS وBrevo SMS وNetgsm خارج النقل بالكامل؛ تبقى حواجز منع الإرسال في الملفات المشتركة.
- اختبارات النقل تستعمل fixtures وهمية ذات نطاق example.invalid فقط.
- القوالب الجديدة تُصاغ لكل جمعية بعد تثبيت الأنظمة، بنصوص وهوية مستقلة.

لا يُعتبر تطابق أسماء الملفات أو SHA إثباتًا لاكتمال ميزة؛ يلزم فحص التبعيات والصلاحيات والبيانات وتجربة التدفق.

## الحزمة الأولى: التقارير
- محرك XLSX/CSV من المرجع المثبت، مع بلد/لغة واضحة، فصل أصل التبرع ودعم الفريق والرسوم، وعدم خلط العملات.
- حالات التحصيل تعتمد نجاحًا مؤكدًا بوقت دفع؛ لا تدخل المحاولات غير المؤكدة في المحصل.
- تحليل الاشتراكات يفرق بين عدد الخطط وعدد المتبرعين وبين المحصل والتوقع، ويبين القيم المفقودة.
- لغة التقرير مستقلة ومعزولة بين الطلبات، واسم الجمعية مستقل عن المصدر.
- اختبارات المصدر المنقولة تحتوي سجلات وهمية فقط. لا تشغيل لأي اتصال ببوابة دفع أو مزود رسائل.
- الحزمة تحتاج تحققًا من بناء كل هدف وتجربة واجهات التصدير؛ اجتياز اختبارات المحرك وحده لا يغلق التكامل.

## اختلافات الأهداف
### قرة العيون
تطوير تفاضلي على النظام الحالي. الحفاظ على مسارات الموقع والبيانات والتخصيصات والصلاحيات الحالية.
### يدي جيهان
المستودع AdhamRef/yedicijan. لا نشر على Vercel. التسليم GitHub ثم أوامر سحب وبناء وإعادة تشغيل ينفذها صاحب السيرفر بعد تحديد المسار واسم العملية وطريقة التشغيل.
نموذج الاشتراك أقدم؛ حقول القراءة الجديدة اختيارية، والسجلات القديمة ذات الدورية الغائبة تعامل كشهرية. لا تشغيل لتحويل بيانات أو تغيير تحصيل.
### وقف الأمة
لوحة مستقلة تستعد لربط موقع PHP قديم. الدفع والتحصيل يبقيان في نظام الموقع القديم.
لا تنشأ صفحات إدارة محتوى صورية أو نسخ مستقلة متعارضة. يلزم عقد API للمحتوى وWebhook موقع للتبرعات ومعرفات خارجية ثابتة وإعادة محاولة ومصالحة.
حزمة التقارير هنا محرك جاهز للاختبار فقط؛ تفعيل التنزيل من البيانات الفعلية ينتظر محول بيانات الربط وصلاحياته.
لا يصح وصف نسخة preview بأنها الإنتاج. يجب إثبات SHA الإنتاج ونجاح الربط قبل الإغلاق.
