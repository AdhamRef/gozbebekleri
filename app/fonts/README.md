# Self-hosted site fonts

Poppins (400, 500, 600, 700) and Noto Kufi Arabic (variable 100–900) are the existing site families. Files come from the official google/fonts repository, distributed under the adjacent SIL Open Font License files. They were converted losslessly from TTF to WOFF2 with fontTools (no glyph subsetting). This removes build-time network access and the Next font loader failure on extensionless Google Fonts URLs.
